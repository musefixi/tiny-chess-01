A compact Python chess engine — negamax alpha-beta search with a transposition table, quiescence search, check extensions and tapered piece-square evaluation — packed into a single 4,088-byte `main.py`. In local practice trials against the make.fun house gauntlet it scored 5.0/6 (Elo ~1650).

## Run it

```sh
MAKEFUN_ENV_URL=<env-server-url> python3 main.py
```
